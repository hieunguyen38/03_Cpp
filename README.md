# CHƯƠNG 01: GIỚI THIỆU VÀ BẮT ĐẦU VỚI C++

## #1. Giới thiệu ngôn ngữ lập trình C++

### 1. Khái niệm

C++ là ngôn ngữ lập trình do **Bjarne Stroustrup** phát triển vào năm 1979 tại Bell Labs, ban đầu với tên gọi "C with Classes". C++ được xây dựng như một **phần mở rộng (extension) của ngôn ngữ C**, bổ sung thêm khả năng **lập trình hướng đối tượng (OOP - Object Oriented Programming)** mà C không có.

### 2. Điểm khác biệt cốt lõi giữa C và C++

> 🎯 Vì bạn đã học C, hãy nhớ nguyên tắc này: **"C++ = C + Classes (Hướng đối tượng) + nhiều tiện ích an toàn hơn"**. Gần như mọi code C hợp lệ đều có thể biên dịch bằng trình biên dịch C++ (trừ một vài khác biệt nhỏ).

| Đặc điểm             | C                                        | C++                                                      |
| -------------------- | ----------------------------------------- | --------------------------------------------------------- |
| **Hướng lập trình**  | Hướng thủ tục (Procedural)               | Đa mô hình: Thủ tục **+ Hướng đối tượng (OOP)**           |
| **Class/Object**     | ❌ Không hỗ trợ                          | ✅ Hỗ trợ đầy đủ (class, object, kế thừa, đa hình...)     |
| **Nhập/Xuất**        | `printf()` / `scanf()`                   | `cout` / `cin` (thư viện `<iostream>`)                    |
| **Quản lý bộ nhớ**   | `malloc()`, `calloc()`, `free()`         | `new`, `delete` (an toàn kiểu hơn)                         |
| **Hàm**              | Không nạp chồng được                     | ✅ Hỗ trợ nạp chồng hàm (Function Overloading)             |
| **Tham chiếu**       | Không có, chỉ có con trỏ                 | ✅ Có thêm References (tham chiếu) `&`                     |
| **Thư viện chuẩn**   | Thư viện C chuẩn (`stdio.h`, `stdlib.h`) | Bổ sung STL (Standard Template Library): vector, map...    |
| **Xử lý lỗi**        | Trả mã lỗi thủ công                      | ✅ Có cơ chế `try/catch/throw` (Exception Handling)        |

### 3. C++ được dùng để làm gì?

- 🔹 **Phát triển game** – Hầu hết game engine lớn (Unreal Engine, một phần Unity) dùng C++ vì tốc độ cao.
- 🔹 **Phần mềm hệ thống** – Hệ điều hành, driver, trình biên dịch.
- 🔹 **Lập trình nhúng hiệu năng cao** – Nơi cần OOP nhưng vẫn cần tốc độ gần phần cứng (ví dụ: firmware phức tạp, robot).
- 🔹 **Ứng dụng hiệu năng cao** – Phần mềm tài chính, mô phỏng khoa học, xử lý ảnh/video.

## #2. Cài đặt môi trường và các công cụ biên dịch

### 1. Các công cụ lập trình C++ phổ biến

**Môi trường PC:**

- 🔥 **VS Code** (kèm Extension _C/C++_ của Microsoft) - Khuyên dùng, nhẹ và tùy biến cao.
- **MinGW / GCC (g++)** - Trình biên dịch C++ chuẩn, miễn phí cho Windows/Linux.
- **Dev-C++, Code::Blocks** - Phù hợp cho người mới bắt đầu, cài đặt nhanh gọn.
- **Trình biên dịch Online** - W3Schools Compiler, OnlineGDB, Compiler Explorer - dùng để test nhanh không cần cài đặt.

> 📌 Lưu ý quan trọng: File mã nguồn C++ dùng đuôi `.cpp` (thay vì `.c` như C), và trình biên dịch tương ứng là `g++` (thay vì `gcc`).

### 2. Biên dịch chương trình C++ bằng Command Line

```bash
g++ main.cpp -o HelloWorldApp.exe   # Biên dịch file .cpp sang file thực thi
./HelloWorldApp.exe                  # Chạy chương trình
```

### 3. So sánh nhanh lệnh biên dịch C vs C++

| Việc cần làm          | Với C (`gcc`)             | Với C++ (`g++`)              |
| ---------------------- | -------------------------- | ------------------------------ |
| Đuôi file mã nguồn     | `.c`                       | `.cpp`, `.cc`, `.cxx`          |
| Lệnh biên dịch         | `gcc main.c -o app`        | `g++ main.cpp -o app`          |

## #3. Cấu trúc một chương trình C++ đầu tiên

### 1. Chương trình Hello World

```cpp
#include <iostream>       // Thư viện chuẩn cho luồng vào/ra (thay cho stdio.h của C)
using namespace std;      // Cho phép dùng cout, cin... mà không cần viết std::

int main() {
    cout << "Hello World! Chao mung ban den voi C++.";  // In ra màn hình bằng cout
    return 0;
}
```

### 2. Phân tích cú pháp từng dòng

| Dòng                       | Ý nghĩa                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `#include <iostream>`      | Nạp thư viện xuất/nhập chuẩn (giống `#include <stdio.h>` trong C nhưng khác cú pháp dùng). |
| `using namespace std;`     | Cho phép gọi thẳng `cout`, `cin` thay vì phải viết `std::cout`, `std::cin`.                |
| `int main() { ... }`       | Hàm chính, nơi chương trình bắt đầu chạy — **giống hệt C**.                               |
| `cout << "..."`            | Đối tượng dùng để xuất dữ liệu, kết hợp với toán tử chèn `<<` (khác `printf()` của C).     |
| `return 0;`                | Kết thúc chương trình, báo hiệu chạy thành công — **giống hệt C**.                        |

> 🎯 **Lời khuyên thực chiến:** Khi mới học, dùng `using namespace std;` cho gọn code. Khi viết dự án lớn/thực tế, nên viết tường minh `std::cout`, `std::cin` để tránh xung đột tên biến với các thư viện khác.

# CHƯƠNG 02: OUTPUT, COMMENT & BIẾN

## #4. Xuất dữ liệu ra màn hình với cout

### 1. Cú pháp cơ bản

`cout` (đọc là "see-out") là đối tượng thuộc thư viện `<iostream>`, dùng cùng **toán tử chèn `<<`** để in dữ liệu ra màn hình.

```cpp
cout << "Hello World!";
```

### 2. In nhiều giá trị & xuống dòng

```cpp
cout << "Toi dang hoc C++"; // Không tự động xuống dòng
cout << "Dong tiep theo";
// Kết quả: Toi dang hoc C++Dong tiep theo (dính liền nhau)

// Cách 1: dùng ký tự thoát \n
cout << "Dong 1\n";
cout << "Dong 2\n";

// Cách 2: dùng endl (xuống dòng + đẩy buffer, chậm hơn \n một chút)
cout << "Dong 1" << endl;
cout << "Dong 2" << endl;
```

### 3. So sánh `printf()` (C) và `cout` (C++)

| Đặc điểm             | `printf()` (C)                         | `cout` (C++)                                  |
| --------------------- | ---------------------------------------- | ----------------------------------------------- |
| **Kiểu dữ liệu**     | Cần format specifier đúng kiểu (`%d`, `%f`, `%s`...) | ❌ Không cần, tự nhận diện kiểu dữ liệu       |
| **Nối chuỗi/biến**    | Dùng dấu phẩy `,` trong ngoặc            | Dùng toán tử chèn `<<` nối liên tiếp            |
| **Rủi ro lỗi**       | Dễ lỗi nếu dùng sai format specifier      | An toàn kiểu hơn vì trình biên dịch tự suy luận |

```cpp
int age = 21;
// Kiểu C:
printf("Tuoi: %d\n", age);
// Kiểu C++:
cout << "Tuoi: " << age << "\n";
```

## #6. Biến (Variables) trong C++

### 1. Cú pháp khai báo

```cpp
<Kieu_du_lieu> <Ten_bien> = <Gia_tri_khoi_tao>;
```

### 2. Ví dụ khai báo và kết hợp kiểu dữ liệu

```cpp
int soLuongSanPham = 100;
double gia = 15990000.5;
char loaiSanPham = 'A';
string tenSanPham = "Laptop Gaming";   // Kiểu string là điểm mới so với C

cout << tenSanPham << " co gia " << gia << " dong.";
```

### 3. Khai báo nhiều biến cùng kiểu & Cộng biến

```cpp
int x = 5, y = 6, z = 50;
cout << x + y + z; // Kết quả: 61

int a = 4;
int b = a;   // b cũng được gán giá trị 4
```

### 4. Quy tắc đặt tên biến (giống hệt C)

- ❌ **Không** bắt đầu bằng chữ số.
- ❌ **Không** chứa khoảng trắng và ký tự đặc biệt (`@`, `#`, `$`...).
- ❌ **Không** trùng từ khóa hệ thống (`int`, `class`, `return`, `new`...).
- 🔹 C++ phân biệt chữ hoa/thường: `mySize` khác `mysize`.

## #7. Hằng số với const

### 1. Khái niệm

Từ khóa `const` dùng để khai báo một biến **không thể thay đổi giá trị** sau khi khởi tạo — cách dùng giống hệt trong C, nhưng trong C++ đây gần như là cách **duy nhất và được khuyến khích** để tạo hằng số (thay vì lạm dụng `#define`).

```cpp
const int TOC_DO_TOI_DA = 120;
```

# CHƯƠNG 03: NHẬP DỮ LIỆU & KIỂU DỮ LIỆU

## #8. Nhập dữ liệu từ người dùng với cin

### 1. Cú pháp cơ bản

`cin` (đọc là "see-in") dùng cùng **toán tử trích xuất `>>`** để nhận dữ liệu từ bàn phím — đây là điểm thay thế cho `scanf()` của C.

```cpp
int soTuoi;
cout << "Nhap tuoi cua ban: ";
cin >> soTuoi;  // Không cần dùng toán tử & như scanf() trong C
cout << "Ban " << soTuoi << " tuoi.";
```

### 2. So sánh `scanf()` (C) và `cin` (C++)

| Đặc điểm              | `scanf()` (C)                              | `cin` (C++)                                  |
| ---------------------- | -------------------------------------------- | ----------------------------------------------- |
| **Toán tử địa chỉ &** | ✅ Bắt buộc: `scanf("%d", &tuoi)`           | ❌ Không cần: `cin >> tuoi`                    |
| **Format specifier**   | ✅ Bắt buộc chỉ định kiểu (`%d`, `%f`...)    | ❌ Tự nhận diện kiểu dữ liệu của biến           |
| **Nhập nhiều giá trị** | `scanf("%d %d", &a, &b);`                    | `cin >> a >> b;`                                |

### 3. Nhập chuỗi (String) — vấn đề khoảng trắng

Giống vấn đề của `scanf("%s", ...)` trong C, `cin >> chuoi` sẽ **dừng đọc tại ký tự khoảng trắng đầu tiên**.

```cpp
string hoTen;
cout << "Nhap ho ten day du: ";
getline(cin, hoTen);   // getline() đọc cả chuỗi có khoảng trắng, tương đương fgets() trong C
cout << "Xin chao, " << hoTen;
```

# CHƯƠNG 08: REFERENCES, POINTERS & QUẢN LÝ BỘ NHỚ

## #24. Tham chiếu (References) trong C++

### 1. Khái niệm — ĐÂY LÀ KHÁI NIỆM HOÀN TOÀN MỚI, C KHÔNG CÓ

Reference là một **bí danh (alias)** — một tên gọi khác cho một biến đã tồn tại. Khai báo bằng dấu `&` đặt sau kiểu dữ liệu.

```cpp
string ten = "Laptop";
string &biDanh = ten;   // bidanh là một tham chiếu (alias) của ten

cout << ten << "\n";      // Laptop
cout << biDanh << "\n";   // Laptop (cùng trỏ tới 1 vùng nhớ)

biDanh = "May tinh bang";
cout << ten;               // May tinh bang (thay đổi qua bidanh làm thay đổi cả ten)
```

### 2. Địa chỉ bộ nhớ với toán tử `&`

```cpp
string food = "Pizza";
cout << &food;  // In ra địa chỉ ô nhớ dạng hexa, ví dụ: 0x6dfed4
```

### 3. Reference vs Pointer — bảng phân biệt cốt lõi

| Đặc điểm                  | Reference (`&`)                              | Pointer (`*`)                                    |
| --------------------------- | ----------------------------------------------- | --------------------------------------------------- |
| **Có thể null?**           | ❌ Không, luôn phải trỏ tới 1 biến hợp lệ      | ✅ Có thể là `nullptr`                              |
| **Đổi đối tượng trỏ tới**  | ❌ Không thể đổi sau khi gán ban đầu           | ✅ Có thể gán lại để trỏ sang biến khác             |
| **Cú pháp truy cập**       | Dùng trực tiếp như biến gốc                     | Phải dereference bằng `*ptr`                        |
| **Độ an toàn**             | An toàn hơn, khó gây lỗi                        | Linh hoạt nhưng dễ gây lỗi nếu dùng sai              |

## #26. Quản lý bộ nhớ động: new & delete

### 1. Tại sao cần quản lý bộ nhớ thủ công?

Khi khai báo biến bình thường, C++ tự động cấp phát và giải phóng bộ nhớ (Stack). Nhưng khi cần tạo bộ nhớ **lúc chương trình đang chạy** (ví dụ dựa theo input người dùng), ta phải tự cấp phát trên Heap và tự giải phóng khi dùng xong.

### 2. Cú pháp `new` và `delete` — thay thế cho `malloc`/`free` của C

```cpp
// Cấp phát 1 biến int trên Heap
int* soLuong = new int;
*soLuong = 50;
cout << *soLuong;
delete soLuong;         // Giải phóng bộ nhớ khi không dùng nữa

// Cấp phát 1 mảng động trên Heap
int* mang = new int[10];  // Tương đương malloc(10 * sizeof(int)) trong C
delete[] mang;             // Dùng delete[] khi giải phóng mảng, không dùng delete thường
```

### 3. So sánh cấp phát bộ nhớ động C vs C++

| Việc cần làm             | C                                  | C++                          |
| -------------------------- | ------------------------------------ | ------------------------------ |
| Cấp phát 1 biến           | `int *p = (int*)malloc(sizeof(int));` | `int* p = new int;`           |
| Cấp phát mảng             | `int *arr = (int*)malloc(n * sizeof(int));` | `int* arr = new int[n];`      |
| Giải phóng 1 biến         | `free(p);`                           | `delete p;`                   |
| Giải phóng mảng           | `free(arr);`                         | `delete[] arr;`                |
| Tự gọi constructor?       | ❌ Không                             | ✅ Có (nếu là object của class) |

> ⚠️ **Cảnh báo Memory Leak:** Giống hệt nguyên tắc trong C — mỗi lần `new` phải có một lần `delete` tương ứng. Quên `delete` sẽ gây rò rỉ bộ nhớ (memory leak), đặc biệt nguy hiểm trong lập trình nhúng vì RAM hạn chế.

## #28. Tham số hàm & Giá trị mặc định

### 1. Truyền tham số: Tham trị (Value) vs Tham chiếu (Reference) — khác biệt với C

Trong C, muốn hàm thay đổi được biến gốc, ta **buộc phải dùng con trỏ**. Trong C++, ta có thêm lựa chọn dùng **tham chiếu (`&`)**, cú pháp gọn hơn nhiều:

```cpp
// Cách C: dùng con trỏ để thay đổi biến gốc

    *soLuong = *soLuong + 1;
}

// Cách C++: dùng tham chiếu, không cần dereference
void tangGiaTriKieuCpp(int &soLuong) {
    soLuong = soLuong + 1;
}

int main() {
    int ton = 10;
    tangGiaTriKieuCpp(ton);  // Gọi hàm không cần lấy địa chỉ &ton như con trỏ
    cout << ton;              // 11
    return 0;
}
```

```cpp
void tinhTongTien(int soLuong, float donGia = 10000) {  // donGia mặc định là 10000 nếu không truyền

}

int main() {
    tinhTongTien(5);          // Dùng đơn giá mặc định: 5 * 10000
```

## #29. Nạp chồng hàm (Function Overloading)

### Khái niệm — ĐIỂM MỚI HOÀN TOÀN, C KHÔNG HỖ TRỢ

C++ cho phép **nhiều hàm cùng tên** miễn là khác nhau về số lượng hoặc kiểu tham số. Trình biên dịch sẽ tự chọn đúng phiên bản hàm phù hợp khi gọi.

```cpp
int cong(int a, int b) {

int cong(int a, int b, int c) {

    return 0;
}
```

## #32. Hàm Lambda trong C++

### Khái niệm — ĐIỂM MỚI HOÀN TOÀN, C KHÔNG HỖ TRỢ (từ C++11)

Lambda là **hàm không tên (anonymous function)**, thường dùng để viết nhanh một đoạn logic ngắn ngay tại chỗ sử dụng, không cần định nghĩa hàm riêng ở nơi khác — rất hữu ích khi làm việc với STL (sẽ học ở Phần V).

```cpp
auto congHaiSo = [](int a, int b) {
```

| ----------------------- | -------------------------------------------------------------------------- |

## #34. Class và Object trong C++

### 1. Khái niệm

- **Class**: là một "khuôn mẫu" (blueprint) định nghĩa các thuộc tính (attributes) và phương thức (methods).

```cpp
class SanPham {          // Định nghĩa Class

```

```
// Kiểu C (chỉ có dữ liệu, xử lý tách rời)
```

## #37. Access Specifiers: public, private, protected

### 1. Ba mức truy cập trong C++ — KHÁI NIỆM MỚI, C KHÔNG CÓ

| Access Specifier | Ý nghĩa                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| `public`           | Thành viên có thể truy cập **từ bên ngoài class**.                                             |
| `private`          | Thành viên **chỉ truy cập được từ bên trong class** — mặc định của `class` nếu không ghi rõ.   |
| `protected`        | Giống `private`, nhưng **class con (kế thừa) vẫn truy cập được** (xem Chương 13).              |

```cpp
class TaiKhoan {
  public:
    string tenDangNhap;   // Truy cập được từ bên ngoài

  private:
    string matKhau;       // KHÔNG truy cập được từ bên ngoài
};

int main() {
    TaiKhoan tk;
    tk.tenDangNhap = "admin";  // ✅ Hợp lệ (public)
    // tk.matKhau = "12345";   // ❌ Lỗi biên dịch (private)
    return 0;
}
```

## #38. Encapsulation (tính đóng gói)

### Khái niệm & Cách triển khai bằng Getter/Setter

Encapsulation nghĩa là **giấu (ẩn) dữ liệu quan trọng bằng `private`**, và chỉ cho phép truy cập/thay đổi thông qua các phương thức `public` gọi là Getter (lấy giá trị) và Setter (gán giá trị) — giúp kiểm soát và xác thực dữ liệu trước khi thay đổi.

```cpp
class TaiKhoanNganHang {
  private:
    double soDu;   // Ẩn đi, không cho sửa trực tiếp từ bên ngoài

  public:
    // Setter - có thể thêm điều kiện kiểm tra trước khi gán
    void datSoDu(double soTien) {
        if (soTien >= 0) {       // Xác thực: không cho số dư âm
            soDu = soTien;
        } else {
            cout << "So tien khong hop le!\n";
        }
    }
    // Getter - lấy giá trị ra ngoài
    double laySoDu() {
        return soDu;
    }
};

int main() {
    TaiKhoanNganHang tk;
    tk.datSoDu(5000000);
    cout << "So du: " << tk.laySoDu();
    return 0;
}
```

> 🎯 **Lợi ích thực chiến:** Nếu để `soDu` là `public`, bất kỳ đoạn code nào cũng có thể gán số âm gây lỗi logic nghiệp vụ. Encapsulation giúp bảo vệ tính toàn vẹn dữ liệu — cực kỳ quan trọng khi làm phần mềm quản lý (giống các hệ thống quản lý tồn kho, giá bán bạn hay làm ở công việc Trade Marketing).

## #39. Friend Functions

### Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ

Một hàm bình thường (không thuộc class) có thể được khai báo là `friend` của class — cho phép hàm đó **truy cập được cả các thành viên `private`/`protected`** của class, dù bản thân nó không phải là phương thức của class.

```cpp
class SanPham {
  private:
    float giaNhap;   // Bí mật, không public

    friend void inGiaNhap(SanPham sp);  // Khai báo hàm bên ngoài là "bạn" của class
  public:
    SanPham(float g) { giaNhap = g; }
};

// Hàm bên ngoài, KHÔNG thuộc class, nhưng vẫn truy cập được private nhờ từ khóa friend
void inGiaNhap(SanPham sp) {
    cout << "Gia nhap noi bo: " << sp.giaNhap;
}

int main() {
    SanPham sp(150000);
    inGiaNhap(sp);   // Gọi hàm friend
    return 0;
}
```

> ⚠️ Friend Function nên dùng hạn chế vì nó phá vỡ nguyên tắc Encapsulation — chỉ dùng khi thực sự cần thiết (ví dụ: nạp chồng toán tử xuất `<<` cho `cout`, hoặc 2 class cần chia sẻ dữ liệu nội bộ chặt chẽ với nhau).

# CHƯƠNG 13: KẾ THỪA (INHERITANCE) & ĐA HÌNH (POLYMORPHISM)

## #40. Inheritance - Tính kế thừa

### 1. Khái niệm

Inheritance cho phép một class (gọi là **class con / derived class**) kế thừa toàn bộ thuộc tính và phương thức từ một class khác (gọi là **class cha / base class**) — giúp tái sử dụng code, tránh viết lại logic trùng lặp.

```cpp
// Class cha (Base class)
class NhanVien {
  protected:              // protected để class con truy cập được (khác private)
    int luongCoBan;

  public:
    void datLuong(int luong) {
        luongCoBan = luong;
    }
};

// Class con (Derived class) kế thừa từ NhanVien
class LapTrinhVien : public NhanVien {
  public:
    int thuongDuAn;

    int tinhTongThuNhap() {
        return luongCoBan + thuongDuAn;  // Dùng lại thuộc tính protected của class cha
    }
};

int main() {
    LapTrinhVien nv;
    nv.datLuong(15000000);   // Phương thức kế thừa từ NhanVien
    nv.thuongDuAn = 3000000;
    cout << "Tong thu nhap: " << nv.tinhTongThuNhap();
    return 0;
}
```

### 2. Các loại kế thừa

| Loại kế thừa            | Mô tả                                                           |
| ------------------------- | ------------------------------------------------------------------ |
| **Đơn kế thừa**          | 1 class con kế thừa từ 1 class cha (ví dụ trên).                   |
| **Đa cấp (Multilevel)**  | A → B → C (C kế thừa B, B kế thừa A).                             |
| **Đa kế thừa (Multiple)**| 1 class con kế thừa từ **nhiều** class cha cùng lúc — C không hỗ trợ khái niệm này ở bất kỳ dạng nào. |

```cpp
// Ví dụ đa kế thừa (Multiple Inheritance) - điểm mạnh riêng của C++
class ThietBiDien {
  public:
    void catDien() { cout << "Da cat dien\n"; }
};
class ThietBiMang {
  public:
    void ngatMang() { cout << "Da ngat mang\n"; }
};
// LaptopGaming kế thừa CẢ HAI class cha cùng lúc
class LaptopGaming : public ThietBiDien, public ThietBiMang {
};
```

## #41. Polymorphism - Tính đa hình

### 1. Khái niệm

Polymorphism ("nhiều hình thái") nghĩa là **cùng một tên phương thức nhưng hoạt động khác nhau** tùy theo class gọi nó — thường dùng kết hợp với Inheritance.

### 2. Đa hình tại thời điểm biên dịch (Compile-time) — chính là Function Overloading

Đã học ở bài #29 — nhiều hàm cùng tên, khác tham số.

### 3. Đa hình tại thời điểm chạy (Runtime) — dùng từ khóa `virtual`

```cpp
class DongVat {
  public:
    virtual void keu() {             // "virtual" cho phép class con ghi đè phương thức này
        cout << "Dong vat phat ra am thanh\n";
    }
};

class Cho : public DongVat {
  public:
    void keu() override {            // Ghi đè (override) phương thức của class cha
        cout << "Cho sua: Gau gau!\n";
    }
};

class Meo : public DongVat {
  public:
    void keu() override {
        cout << "Meo keu: Meo meo!\n";
    }
};

int main() {
    DongVat* dsDongVat[2];   // Mảng con trỏ kiểu class cha
    Cho cho1;
    Meo meo1;

    dsDongVat[0] = &cho1;
    dsDongVat[1] = &meo1;

    for (int i = 0; i < 2; i++) {
        dsDongVat[i]->keu();  // Cùng gọi keu() nhưng mỗi con vật kêu khác nhau (Runtime Polymorphism)
    }
    return 0;
}
```

### 4. So sánh Overloading vs Overriding

| Đặc điểm            | Function Overloading (Nạp chồng)     | Function Overriding (Ghi đè)                     |
| --------------------- | ---------------------------------------- | ---------------------------------------------------- |
| **Xảy ra khi nào**   | Cùng 1 class, nhiều hàm cùng tên          | Class con định nghĩa lại hàm của class cha           |
| **Yêu cầu kế thừa?** | ❌ Không cần                             | ✅ Bắt buộc phải có quan hệ kế thừa                  |
| **Từ khóa cần dùng** | Không cần từ khóa đặc biệt                | Cần `virtual` (ở class cha) và `override` (ở class con) |
| **Thời điểm quyết định** | Lúc biên dịch (Compile-time)          | Lúc chạy chương trình (Runtime)                      |

# CHƯƠNG 14: TEMPLATE, FILE & THỜI GIAN

## #42. Templates trong C++

### 1. Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ

Template cho phép viết **một hàm hoặc class dùng chung cho nhiều kiểu dữ liệu khác nhau**, tránh việc phải nạp chồng thủ công quá nhiều phiên bản (như bài #29).

### 2. Function Template

```cpp
template <typename T>          // Khai báo T là kiểu dữ liệu tổng quát (generic type)
T timGiaTriLonNhat(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << timGiaTriLonNhat(10, 25) << "\n";       // T tự suy ra là int: 25
    cout << timGiaTriLonNhat(3.5, 2.1) << "\n";     // T tự suy ra là double: 3.5
    cout << timGiaTriLonNhat<string>("Tao", "Le") << "\n"; // Chỉ định rõ T là string
    return 0;
}
```

### 3. Class Template

```cpp
template <class T>
class HopChua {
  private:
    T giaTri;
  public:
    HopChua(T val) { giaTri = val; }
    T layGiaTri() { return giaTri; }
};

int main() {
    HopChua<int> hopSo(100);
    HopChua<string> hopChu("Xin chao");

    cout << hopSo.layGiaTri() << "\n";
    cout << hopChu.layGiaTri() << "\n";
    return 0;
}
```

> 🎯 Bản thân các cấu trúc dữ liệu STL bạn sẽ học ở Phần V (như `vector<int>`, `map<string, int>`) đều được xây dựng dựa trên Template — đây chính là lý do vì sao cú pháp STL luôn có dấu `<>`.

## #47. Exception Handling: try, catch, throw

### Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ (C chỉ trả mã lỗi thủ công qua return code)

C++ cung cấp cơ chế xử lý lỗi runtime có cấu trúc bằng 3 từ khóa: `try` (thử chạy code), `throw` (ném ra lỗi/ngoại lệ), `catch` (bắt và xử lý lỗi).

```cpp
int main() {
    int tuSo = 10;
    int mauSo = 0;

    try {
        if (mauSo == 0) {
            throw runtime_error("Khong the chia cho 0!");  // Ném ra ngoại lệ
        }
        cout << tuSo / mauSo;
    }
    catch (const runtime_error& loi) {   // Bắt và xử lý ngoại lệ vừa ném ra
        cout << "Da bat loi: " << loi.what();
    }

    return 0;
}
```

### So sánh cách xử lý lỗi C vs C++

| Cách tiếp cận         | C                                                | C++                                          |
| ------------------------ | --------------------------------------------------- | ----------------------------------------------- |
| **Cơ chế**              | Trả mã lỗi qua giá trị `return` hoặc biến `errno`   | Cơ chế `try/catch/throw` có cấu trúc rõ ràng     |
| **Điểm mạnh**           | Đơn giản, hiệu năng cao (phù hợp nhúng)              | Tách biệt code xử lý lỗi khỏi logic chính        |
| **Điểm yếu**            | Dễ quên kiểm tra mã lỗi, code kiểm tra rải rác       | Có overhead hiệu năng nhỏ hơn so với C           |

## #50. Vector - Mảng động trong C++

### 1. Khái niệm

`vector` là mảng động — **tự động thay đổi kích thước** khi thêm/xóa phần tử, khắc phục nhược điểm lớn nhất của mảng tĩnh trong C (kích thước cố định).

```cpp
#include <vector>

int main() {
    vector<string> danhSachSanPham = {"Chuot", "Ban phim", "Tai nghe"};

    danhSachSanPham.push_back("Man hinh");   // Thêm phần tử vào cuối
    danhSachSanPham.pop_back();               // Xóa phần tử cuối cùng

    cout << danhSachSanPham[0] << "\n";       // Truy cập như mảng thường: Chuot
    cout << danhSachSanPham.size() << "\n";   // Số lượng phần tử hiện có

    for (string sp : danhSachSanPham) {       // Duyệt bằng range-based for (bài #19)
        cout << sp << "\n";
    }
    return 0;
}
```

### 2. Các thao tác thường dùng với Vector

| Phương thức          | Ý nghĩa                                  |
| ---------------------- | -------------------------------------------- |
| `push_back(x)`         | Thêm phần tử `x` vào cuối vector             |
| `pop_back()`           | Xóa phần tử cuối cùng                        |
| `size()`               | Trả về số lượng phần tử hiện có              |
| `empty()`              | Kiểm tra vector có rỗng không                |
| `clear()`              | Xóa toàn bộ phần tử                          |
| `insert(vt, x)`        | Chèn phần tử `x` vào vị trí `vt`             |
| `erase(vt)`            | Xóa phần tử tại vị trí `vt`                  |

> 🎯 **Lời khuyên thực chiến:** Trong hầu hết dự án C++ hiện đại, `vector` được dùng thay thế cho mảng tĩnh (bài #21) trong 90% trường hợp vì tính linh hoạt và các hàm hỗ trợ dựng sẵn.

### 1. Stack (Ngăn xếp) — nguyên lý LIFO (Last In First Out)

## #57. Algorithm - Thư viện thuật toán có sẵn

### Khái niệm

Thư viện `<algorithm>` cung cấp sẵn các thuật toán phổ biến (sắp xếp, tìm kiếm, đảo ngược...) áp dụng được cho hầu hết mọi container STL — giúp bạn không cần tự code lại thuật toán sắp xếp như khi học Cấu trúc dữ liệu bằng C.

```cpp
#include <algorithm>
#include <vector>

int main() {
    vector<int> soLuongTon = {50, 12, 88, 5, 33};

    sort(soLuongTon.begin(), soLuongTon.end());          // Sắp xếp tăng dần
    for (int x : soLuongTon) cout << x << " ";            // 5 12 33 50 88
    cout << "\n";

    reverse(soLuongTon.begin(), soLuongTon.end());        // Đảo ngược thứ tự
    for (int x : soLuongTon) cout << x << " ";            // 88 50 33 12 5
    cout << "\n";

    auto viTri = find(soLuongTon.begin(), soLuongTon.end(), 33); // Tìm kiếm phần tử
    if (viTri != soLuongTon.end()) {
        cout << "Tim thay 33 trong danh sach";
    }
    return 0;
}
```

| Hàm                          | Ý nghĩa                              |
| ------------------------------ | ---------------------------------------- |
| `sort(begin, end)`             | Sắp xếp tăng dần                         |
| `reverse(begin, end)`          | Đảo ngược thứ tự các phần tử             |
| `find(begin, end, giaTri)`     | Tìm kiếm giá trị, trả về iterator        |
| `max_element(begin, end)`      | Tìm phần tử lớn nhất                     |
| `min_element(begin, end)`      | Tìm phần tử nhỏ nhất                     |

# CHƯƠNG 20: NAMESPACE TRONG C++

## #58. Namespace - Không gian tên

### Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ

Namespace dùng để **nhóm các tên (biến, hàm, class) lại với nhau**, tránh xung đột tên khi 2 thư viện/module khác nhau vô tình đặt trùng tên định danh — đây chính là nguồn gốc của cụm từ `using namespace std;` mà bạn đã dùng xuyên suốt tài liệu này.

```cpp
namespace KhoHang {
    int soLuongTon = 100;
    void hienThiTonKho() {
        cout << "So luong ton: " << soLuongTon;
    }
}

namespace CuaHang {
    int soLuongTon = 50;   // Trùng tên biến với namespace KhoHang nhưng KHÔNG xung đột
}

int main() {
    cout << KhoHang::soLuongTon << "\n";  // Truy cập qua toán tử phạm vi ::
    cout << CuaHang::soLuongTon << "\n";
    KhoHang::hienThiTonKho();
    return 0;
}
```

> 📌 `std` chính là namespace chứa toàn bộ thư viện chuẩn của C++ (`cout`, `cin`, `vector`, `string`...). Khi viết `using namespace std;`, bạn đang nói với trình biên dịch: "cho phép tôi dùng thẳng tên trong namespace std mà không cần viết `std::` phía trước".

# CHƯƠNG 21: BẢNG SO SÁNH TỔNG HỢP C vs C++

## #59. So sánh chi tiết C và C++

### Bảng tổng hợp toàn diện — dùng để ôn tập nhanh trước khi phỏng vấn hoặc chuyển đổi tư duy

| Tiêu chí                     | C                                          | C++                                                          |
| ------------------------------ | --------------------------------------------- | ---------------------------------------------------------------- |
| **Mô hình lập trình**         | Thủ tục (Procedural)                          | Đa mô hình: Thủ tục + Hướng đối tượng (OOP)                      |
| **File mã nguồn**             | `.c`                                          | `.cpp`, `.cc`, `.cxx`                                             |
| **Trình biên dịch**           | `gcc`                                         | `g++`                                                             |
| **Xuất/Nhập dữ liệu**         | `printf()` / `scanf()`                        | `cout` / `cin` (vẫn dùng được `printf`/`scanf` nếu muốn)          |
| **Kiểu chuỗi**                | `char[]` + thư viện `<string.h>`              | `string` object + thư viện `<string>`                             |
| **Cấp phát bộ nhớ động**      | `malloc()`, `calloc()`, `realloc()`, `free()` | `new`, `delete`, `new[]`, `delete[]`                              |
| **Con trỏ null**              | `NULL`                                        | `nullptr` (an toàn kiểu hơn)                                      |
| **Tham chiếu (Reference)**    | ❌ Không có, chỉ có con trỏ                   | ✅ Có (`&`), thay thế con trỏ trong nhiều trường hợp              |
| **Struct**                    | Không chứa hàm, không có access specifier     | Có thể chứa hàm, có access specifier (`public/private/protected`) |
| **Class & Object**            | ❌ Không hỗ trợ                               | ✅ Hỗ trợ đầy đủ                                                  |
| **Nạp chồng hàm (Overload)**  | ❌ Không hỗ trợ                               | ✅ Hỗ trợ                                                         |
| **Kế thừa (Inheritance)**     | ❌ Không có                                   | ✅ Có (đơn, đa cấp, đa kế thừa)                                   |
| **Đa hình (Polymorphism)**    | ❌ Không có (phải giả lập bằng con trỏ hàm)   | ✅ Có (`virtual`, `override`)                                     |
| **Template / Generic**        | ❌ Không có (dùng macro hoặc `void*`)         | ✅ Có (Function Template, Class Template)                          |
| **Xử lý lỗi**                 | Trả mã lỗi thủ công / `errno`                 | `try / catch / throw` (Exception Handling)                        |
| **Cấu trúc dữ liệu dựng sẵn** | ❌ Không có, phải tự cài đặt                  | ✅ STL: `vector`, `list`, `stack`, `queue`, `map`, `set`...        |
| **Namespace**                 | ❌ Không có                                   | ✅ Có, tránh xung đột tên định danh                               |
| **Ứng dụng nhúng**            | Rất phổ biến (nhẹ, tối ưu tối đa)             | Vẫn dùng được, phù hợp dự án nhúng cần tổ chức code lớn hơn (OOP)  |

> 🎯 **Tổng kết bằng một câu:** Nếu C dạy bạn cách **điều khiển máy tính ở mức thấp một cách chính xác**, thì C++ dạy bạn cách **tổ chức một hệ thống phần mềm lớn, dễ bảo trì và mở rộng** — bằng cách xây dựng thêm lớp trừu tượng OOP lên trên chính nền tảng C mà bạn đã có.

## #61. Bài tập tổng hợp: Quản lý danh sách sản phẩm bằng Class + STL

### Yêu cầu

Xây dựng chương trình quản lý sản phẩm đơn giản, áp dụng tổng hợp: **Class + Encapsulation + Constructor + Vector + Algorithm** — mô phỏng đúng bài toán quản lý SKU/tồn kho trong thực tế công việc Trade Marketing.

- Mỗi sản phẩm gồm: tên, giá, số lượng tồn.
- Cho phép thêm sản phẩm vào danh sách (dùng `vector`).
- Tính tổng giá trị tồn kho.
- Sắp xếp danh sách theo giá tăng dần (dùng `<algorithm>`).

### Code tham khảo

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

class SanPham {
  private:
    string ten;
    float gia;
    int soLuongTon;

  public:
    // Constructor
    SanPham(string t, float g, int sl) {
        ten = t;
        gia = g;
        soLuongTon = sl;
    }

    // Getter
    float layGia() const { return gia; }
    float tinhGiaTriTon() const { return gia * soLuongTon; }

    void hienThi() const {
        cout << ten << " | Gia: " << gia << " VND | Ton: " << soLuongTon << "\n";
    }
};

int main() {
    vector<SanPham> danhSachSP;   // Vector chứa các Object thuộc class SanPham

    // Thêm sản phẩm vào danh sách
    danhSachSP.push_back(SanPham("Chuot khong day", 250000, 30));
    danhSachSP.push_back(SanPham("Ban phim co", 890000, 15));
    danhSachSP.push_back(SanPham("Man hinh 24 inch", 3500000, 8));

    // Sắp xếp theo giá tăng dần bằng Lambda + Algorithm
    sort(danhSachSP.begin(), danhSachSP.end(), [](const SanPham &a, const SanPham &b) {
        return a.layGia() < b.layGia();
    });

    cout << "=== DANH SACH SAN PHAM (SAP XEP THEO GIA) ===\n";
    float tongGiaTriTonKho = 0;
    for (const auto &sp : danhSachSP) {
        sp.hienThi();
        tongGiaTriTonKho += sp.tinhGiaTriTon();
    }

    cout << "\nTong gia tri ton kho: " << tongGiaTriTonKho << " VND";
    return 0;
}
```

### Giải thích các điểm áp dụng kiến thức đã học

| Kiến thức áp dụng          | Vị trí trong code                                              |
| ----------------------------- | ------------------------------------------------------------------ |
| Class + Encapsulation (#34, #38) | `private` cho dữ liệu, `public` cho getter/hiển thị              |
| Constructor (#36)             | `SanPham(string t, float g, int sl)`                               |
| Vector - STL (#50)            | `vector<SanPham> danhSachSP` chứa các object                       |
| Lambda (#32)                  | Hàm so sánh truyền vào `sort()`                                     |
| Algorithm (#57)               | `sort(danhSachSP.begin(), danhSachSP.end(), ...)`                   |
| Range-based for (#19)         | `for (const auto &sp : danhSachSP)`                                 |
