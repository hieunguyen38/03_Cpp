# CHƯƠNG 01: GIỚI THIỆU VÀ BẮT ĐẦU VỚI C++

## #1. Giới thiệu ngôn ngữ lập trình C++

### 1. Khái niệm

C++ do **Bjarne Stroustrup** phát triển năm 1979 tại Bell Labs, ban đầu tên là "C with Classes". C++ là **phần mở rộng của C**, bổ sung khả năng **lập trình hướng đối tượng (OOP)** mà C không có.

> 🎯 Nguyên tắc cốt lõi: **"C++ = C + Classes (OOP) + nhiều tiện ích an toàn hơn"**. Gần như mọi code C hợp lệ đều biên dịch được bằng trình biên dịch C++.

### 2. Điểm khác biệt cốt lõi giữa C và C++

| Đặc điểm             | C                                        | C++                                                      |
| -------------------- | ----------------------------------------- | --------------------------------------------------------- |
| **Hướng lập trình**  | Hướng thủ tục (Procedural)               | Đa mô hình: Thủ tục **+ Hướng đối tượng (OOP)**           |
| **Class/Object**     | ❌ Không hỗ trợ                          | ✅ Hỗ trợ đầy đủ                                          |
| **Nhập/Xuất**        | `printf()` / `scanf()`                   | `cout` / `cin` (`<iostream>`)                              |
| **Quản lý bộ nhớ**   | `malloc()`, `free()`                     | `new`, `delete`                                            |
| **Hàm**              | Không nạp chồng được                     | ✅ Hỗ trợ nạp chồng hàm                                    |
| **Tham chiếu**       | Không có, chỉ có con trỏ                 | ✅ Có thêm References `&`                                  |
| **Thư viện chuẩn**   | `stdio.h`, `stdlib.h`                    | STL: `vector`, `map`, `string`...                          |
| **Xử lý lỗi**        | Trả mã lỗi thủ công                      | ✅ `try/catch/throw`                                       |

### 3. C++ được dùng để làm gì?

- 🔹 **Phát triển game** – Game engine lớn (Unreal Engine...) dùng C++ vì tốc độ cao.
- 🔹 **Phần mềm hệ thống** – Hệ điều hành, driver, trình biên dịch.
- 🔹 **Lập trình nhúng hiệu năng cao** – Firmware phức tạp cần tổ chức code bằng OOP.
- 🔹 **Ứng dụng hiệu năng cao** – Phần mềm tài chính, mô phỏng khoa học.

## #3. Cấu trúc một chương trình C++ đầu tiên (Syntax)

### 1. Chương trình Hello World

```cpp
#include <iostream>       // Thư viện chuẩn cho luồng vào/ra (thay cho stdio.h của C)
using namespace std;      // Cho phép dùng cout, cin... mà không cần viết std::

int main() {
    cout << "Hello World! Chao mung ban den voi C++.";
    return 0;
}
```

### 2. Phân tích cú pháp từng dòng

| Dòng                       | Ý nghĩa                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `#include <iostream>`      | Nạp thư viện xuất/nhập chuẩn.                                                              |
| `using namespace std;`     | Cho phép gọi thẳng `cout`, `cin` thay vì `std::cout`, `std::cin`.                          |
| `int main() { ... }`       | Hàm chính, nơi chương trình bắt đầu chạy — giống hệt C.                                    |
| `cout << "..."`            | Xuất dữ liệu, kết hợp toán tử chèn `<<` (khác `printf()` của C).                            |
| `return 0;`                | Kết thúc chương trình thành công — giống hệt C.                                            |

### 3. Về việc dùng `using namespace std;`

Trong tài liệu này ta dùng `using namespace std;` cho code ngắn gọn, dễ học. Trong dự án lớn, nhiều lập trình viên viết tường minh `std::cout` để tránh xung đột tên (xem thêm bài #26 - Omitting Namespace).

# CHƯƠNG 02: OUTPUT & COMMENT

## #4. Xuất dữ liệu ra màn hình với cout

### 1. Cú pháp cơ bản

`cout` (đọc "see-out") dùng cùng **toán tử chèn `<<`** để in dữ liệu ra màn hình.

```cpp
cout << "Hello World!";
```

### 2. In liên tiếp không tự xuống dòng

```cpp
cout << "Hello World!";
cout << "I am learning C++";
// Kết quả dính liền: Hello World!I am learning C++
```

### 3. So sánh `printf()` (C) và `cout` (C++)

| Đặc điểm             | `printf()` (C)                         | `cout` (C++)                                  |
| --------------------- | ---------------------------------------- | ----------------------------------------------- |
| **Kiểu dữ liệu**     | Cần format specifier (`%d`, `%f`, `%s`) | ❌ Không cần, tự nhận diện kiểu                |
| **Nối chuỗi/biến**    | Dùng dấu phẩy trong ngoặc                | Dùng `<<` nối liên tiếp                        |

## #5. Xuống dòng (New Lines)

### 1. Dùng ký tự thoát `\n`

```cpp
cout << "Hello World! \n";
cout << "I am learning C++";
```

### 2. Dùng `endl`

```cpp
cout << "Hello World!" << endl;
```

| **Format specifier**   | ✅ Bắt buộc (`%d`, `%f`...)            | ❌ Tự nhận diện kiểu dữ liệu     |
| **Nhập nhiều giá trị** | `scanf("%d %d", &a, &b);`             | `cin >> a >> b;`                  |

# CHƯƠNG 05: TOÁN TỬ (OPERATORS)

## #18. Toán tử số học, gán, so sánh, logic & bitwise

### 1. Toán tử số học (Arithmetic)

| Toán tử | Tên gọi        | Mô tả                          | Ví dụ    |
| ------- | --------------- | -------------------------------- | -------- |
| `+`     | Cộng            | Cộng 2 giá trị                    | `x + y`  |
| `-`     | Trừ             | Trừ giá trị này cho giá trị kia   | `x - y`  |
| `*`     | Nhân            | Nhân 2 giá trị                    | `x * y`  |
| `/`     | Chia            | Chia giá trị này cho giá trị kia  | `x / y`  |
| `%`     | Chia lấy dư     | Trả về phần dư của phép chia      | `x % y`  |
| `++`    | Tăng            | Tăng giá trị biến lên 1           | `++x`    |
| `--`    | Giảm            | Giảm giá trị biến đi 1            | `--x`    |

### 2. Toán tử gán (Assignment)

| Toán tử | Ví dụ    | Tương đương  |
| ------- | -------- | ------------- |
| `=`     | `x = 5`  | `x = 5`       |
| `+=`    | `x += 3` | `x = x + 3`   |
| `-=`    | `x -= 3` | `x = x - 3`   |
| `*=`    | `x *= 3` | `x = x * 3`   |
| `/=`    | `x /= 3` | `x = x / 3`   |
| `%=`    | `x %= 3` | `x = x % 3`   |

### 3. Toán tử so sánh (Comparison)

| Toán tử | Tên gọi           | Ví dụ    |
| ------- | ------------------ | -------- |

| `!=`    | Khác                | `x != y` |
| `>`     | Lớn hơn            | `x > y`  |
| `<`     | Nhỏ hơn            | `x < y`  |
| `>=`    | Lớn hơn hoặc bằng  | `x >= y` |
| `<=`    | Nhỏ hơn hoặc bằng  | `x <= y` |

### 4. Toán tử logic (Logical)

| Toán tử | Tên gọi | Mô tả                                             |
| ------- | -------- | ---------------------------------------------------- |
| `&&`    | AND      | Trả về true nếu CẢ HAI điều kiện đều đúng             |
| `\|\|`  | OR       | Trả về true nếu ÍT NHẤT MỘT điều kiện đúng            |
| `!`     | NOT      | Đảo ngược kết quả logic                               |

### 5. Toán tử bitwise (thao tác bit) — giống hệt C

| Toán tử | Tên gọi              | Mô tả                          |
| ------- | --------------------- | -------------------------------- |
| `&`     | AND bit               | So sánh từng bit                 |
| `\|`    | OR bit                | So sánh từng bit                 |
| `^`     | XOR bit               | So sánh từng bit                 |
| `~`     | NOT bit (đảo bit)     | Đảo toàn bộ bit                  |
| `<<`    | Dịch trái             | Dịch các bit sang trái            |
| `>>`    | Dịch phải             | Dịch các bit sang phải            |

```cpp
cout << a + b << "\n";   // 13
```

## #20. Concatenation - Nối chuỗi

### 2. Nối bằng hàm `append()`

## #27. C-Style Strings - Chuỗi kiểu C trong C++

C++ vẫn hỗ trợ đầy đủ chuỗi kiểu C (mảng `char[]` kết thúc bằng ký tự null `\0`) — hữu ích khi làm việc với API hệ thống hoặc code nhúng cũ:

```cpp
char tenC[] = "Hello";     // Chuỗi kiểu C - mảng ký tự, tự động thêm '\0' ở cuối
cout << tenC;

#include <cstring>          // Tương đương string.h trong C
char a[] = "Xin ";
char b[] = "chao";
strcat(a, b);                // Nối chuỗi kiểu C - giống hệt C
cout << a;                    // "Xin chao"
```

### So sánh nhanh: `string` (C++) vs C-Style String (`char[]`)

| Đặc điểm         | `string` (C++)                  | C-Style String (`char[]`)        |
| ------------------ | ------------------------------- | ----------------------------------- |
| Thư viện           | `<string>`                       | `<cstring>` (tương đương string.h)  |
| Nối chuỗi          | `a + b` hoặc `a.append(b)`       | `strcat(a, b)`                       |
| Độ dài             | `a.length()`                     | `strlen(a)`                          |
| Độ an toàn         | Cao — tự quản lý bộ nhớ           | Thấp — dễ tràn bộ nhớ nếu sai kích thước |

| `substr(i, n)`  | Trả về chuỗi con bắt đầu từ vị trí `i`, dài `n` ký tự                  |
| `find(x)`       | Trả về vị trí xuất hiện đầu tiên của `x` trong chuỗi                    |
| `rfind(x)`      | Trả về vị trí xuất hiện cuối cùng của `x` trong chuỗi                   |
| `replace(...)`  | Thay thế một phần chuỗi bằng chuỗi khác                                |
| `insert(i, x)`  | Chèn chuỗi `x` vào vị trí `i`                                          |
| `erase(i, n)`   | Xóa `n` ký tự bắt đầu từ vị trí `i`                                    |
| `compare(x)`    | So sánh 2 chuỗi (trả về 0 nếu bằng nhau)                                |

```cpp
string txt = "Xin chao cac ban";
cout << txt.substr(4, 4);   // "chao"
cout << txt.find("cac");     // Vị trí bắt đầu của "cac"
```

## #50. Địa chỉ bộ nhớ (Memory Address)

Khi một biến được tạo ra, nó được cấp một địa chỉ ô nhớ. Dùng toán tử `&` để lấy địa chỉ đó:

```cpp
string food = "Pizza";

cout << &food << "\n";  // Xuất địa chỉ ô nhớ, dạng hexa: 0x6dfed4
```

> 📌 References và Pointers (2 bài tiếp theo) là các tính năng giúp C++ **thao tác trực tiếp với bộ nhớ máy tính** — giảm code và tăng hiệu năng, đây là điểm làm C++ nổi bật so với các ngôn ngữ như Python hay Java.

## #51. References - Tham chiếu

### Khái niệm — HOÀN TOÀN MỚI, C KHÔNG CÓ

Reference là một **bí danh (alias)** — tên gọi khác cho một biến đã tồn tại, khai báo bằng dấu `&` sau kiểu dữ liệu.

```cpp
string ten = "Laptop";
string &biDanh = ten;   // biDanh là một tham chiếu (alias) của ten

cout << ten << "\n";      // Laptop
cout << biDanh << "\n";   // Laptop (cùng trỏ tới 1 vùng nhớ)

biDanh = "May tinh bang";
cout << ten;               // May tinh bang (đổi qua biDanh làm đổi cả ten)
```

### Reference vs Pointer — bảng phân biệt cốt lõi

| Đặc điểm                  | Reference (`&`)                    | Pointer (`*`)                          |
| --------------------------- | -------------------------------------- | ------------------------------------------ |
| **Có thể null?**           | ❌ Không, luôn trỏ tới 1 biến hợp lệ  | ✅ Có thể là `nullptr`                    |
| **Đổi đối tượng trỏ tới**  | ❌ Không thể đổi sau khi gán ban đầu  | ✅ Có thể gán lại để trỏ sang biến khác   |
| **Cú pháp truy cập**       | Dùng trực tiếp như biến gốc            | Phải dereference bằng `*ptr`               |

## #52. Pointers - Con trỏ cơ bản

```cpp
string food = "Pizza";
string* ptr = &food;    // Khai báo con trỏ trỏ tới food

cout << food << "\n";   // Pizza
cout << &food << "\n";  // Địa chỉ ô nhớ của food
cout << ptr << "\n";    // Địa chỉ ô nhớ của food (giống &food)
```

> 📌 Có 3 cách viết con trỏ hợp lệ, nhưng C++ khuyến khích cách đầu tiên: `string* ptr;` thay vì `string *ptr;` hay `string * ptr;` — khác thói quen phổ biến khi học C.

### So sánh con trỏ C vs C++

| Đặc điểm             | C                                | C++                                            |
| ---------------------- | ----------------------------------- | -------------------------------------------------- |
| **Cấp phát động**     | `malloc()` / `free()`               | `new` / `delete` (an toàn kiểu hơn)                 |
| **Con trỏ null**      | `NULL`                               | `nullptr` (an toàn kiểu hơn, khuyến khích từ C++11) |

## #53. Dereference - Giải tham chiếu con trỏ

```cpp
string food = "Pizza";
string* ptr = &food;

cout << ptr << "\n";    // Reference: in địa chỉ ô nhớ
cout << *ptr << "\n";   // Dereference: in giá trị mà con trỏ trỏ tới ("Pizza")
```

Dấu `*` có 2 vai trò khác nhau:

- Khi dùng lúc khai báo (`string* ptr`): tạo một biến con trỏ.
- Khi KHÔNG dùng lúc khai báo (`*ptr`): đóng vai trò toán tử dereference (giải tham chiếu).

## #54. Modify Pointers - Thay đổi giá trị qua con trỏ

## #55. Quản lý bộ nhớ động: new & delete

### 1. Tại sao cần quản lý bộ nhớ thủ công?

Khi khai báo biến bình thường, C++ tự động cấp phát/giải phóng bộ nhớ (Stack). Nhưng khi cần tạo bộ nhớ **lúc chương trình đang chạy** (VD: dựa theo input người dùng), ta phải tự cấp phát trên Heap và tự giải phóng khi dùng xong.

### 2. Cú pháp `new` và `delete` — thay thế `malloc`/`free` của C

```cpp
// Cấp phát 1 biến int trên Heap
int* soLuong = new int;
*soLuong = 50;
cout << *soLuong;
delete soLuong;         // Giải phóng bộ nhớ khi không dùng nữa

// Cấp phát 1 mảng động trên Heap
int* mang = new int[10];  // Tương đương malloc(10 * sizeof(int)) trong C
delete[] mang;             // Dùng delete[] khi giải phóng mảng
```

### 3. So sánh cấp phát bộ nhớ động C vs C++

| Việc cần làm             | C                                    | C++                       |
| -------------------------- | --------------------------------------- | ---------------------------- |
| Cấp phát 1 biến           | `int *p = (int*)malloc(sizeof(int));`   | `int* p = new int;`         |
| Cấp phát mảng             | `int *arr = (int*)malloc(n*sizeof(int));`| `int* arr = new int[n];`   |
| Giải phóng 1 biến         | `free(p);`                              | `delete p;`                  |
| Giải phóng mảng           | `free(arr);`                            | `delete[] arr;`               |

> ⚠️ **Cảnh báo Memory Leak:** Mỗi lần `new` phải có một lần `delete` tương ứng. Quên `delete` sẽ gây rò rỉ bộ nhớ — đặc biệt nguy hiểm trong lập trình nhúng vì RAM hạn chế.

## #57. Tham số hàm (Function Parameters)

### 1. Truyền tham số: Tham trị (Value) vs Tham chiếu (Reference)

Trong C, muốn hàm thay đổi biến gốc, phải dùng con trỏ. Trong C++, có thêm lựa chọn dùng **tham chiếu (`&`)**, gọn hơn nhiều:

```cpp

    *soLuong = *soLuong + 1;
}

// Cách C++: dùng tham chiếu, không cần dereference
void tangGiaTriKieuCpp(int &soLuong) {
    soLuong = soLuong + 1;
}

int main() {
    int ton = 10;
    tangGiaTriKieuCpp(ton);  // Không cần lấy địa chỉ &ton như con trỏ
    cout << ton;              // 11
    return 0;
}
```

### 2. Nhiều tham số (Multiple Parameters)


## #68. Access Specifiers: public, private, protected

### Ba mức truy cập — KHÁI NIỆM MỚI, C KHÔNG CÓ

| Access Specifier | Ý nghĩa                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| `public`           | Truy cập được **từ bên ngoài class**.                                                          |
| `private`          | **Chỉ truy cập được từ bên trong class** — mặc định của `class` nếu không ghi rõ.              |
| `protected`        | Giống `private`, nhưng **class con (kế thừa) vẫn truy cập được** (xem Chương 19).              |

```cpp
class TaiKhoan {
  public:
    string tenDangNhap;

  private:
    string matKhau;
};

int main() {
    TaiKhoan tk;
    tk.tenDangNhap = "admin";  // ✅ Hợp lệ (public)
    // tk.matKhau = "12345";   // ❌ Lỗi biên dịch (private)
    return 0;
}
```

> 📌 `struct` mặc định là `public`, còn `class` mặc định là `private` nếu không ghi rõ access specifier — đây là khác biệt kỹ thuật còn sót lại giữa `struct` và `class`.

## #69. Encapsulation (tính đóng gói)

### Cách triển khai bằng Getter/Setter

Encapsulation nghĩa là **giấu dữ liệu quan trọng bằng `private`**, chỉ cho truy cập/thay đổi qua các phương thức `public` (Getter/Setter) — giúp kiểm soát dữ liệu trước khi thay đổi.

```cpp
class TaiKhoanNganHang {
  private:
    double soDu;

  public:
    void datSoDu(double soTien) {          // Setter - có thể kiểm tra điều kiện
        if (soTien >= 0) {
            soDu = soTien;
        } else {
            cout << "So tien khong hop le!\n";
        }
    }
    double laySoDu() {                      // Getter
        return soDu;
    }
};

int main() {
    TaiKhoanNganHang tk;
    tk.datSoDu(5000000);
    cout << "So du: " << tk.laySoDu();
    return 0;
}
```

> 🎯 **Lợi ích thực chiến:** Nếu để `soDu` là `public`, bất kỳ đoạn code nào cũng có thể gán số âm gây lỗi logic. Encapsulation giúp bảo vệ tính toàn vẹn dữ liệu — quan trọng khi làm phần mềm quản lý tồn kho/giá bán.

## #70. Friend Functions

### Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ

Một hàm bình thường (không thuộc class) có thể khai báo `friend` của class — cho phép truy cập cả thành viên `private`/`protected` dù bản thân không phải phương thức của class.

```cpp
class SanPham {

    float giaNhap;

    friend void inGiaNhap(SanPham sp);  // Khai báo hàm bên ngoài là "bạn" của class
  public:

void inGiaNhap(SanPham sp) {

}

int main() {
    SanPham sp(150000);
    inGiaNhap(sp);
    return 0;
}
```

> ⚠️ Friend Function nên dùng hạn chế vì phá vỡ nguyên tắc Encapsulation — chỉ dùng khi thực sự cần thiết.

# CHƯƠNG 19: KẾ THỪA (INHERITANCE) & ĐA HÌNH (POLYMORPHISM)

## #71. Inheritance - Kế thừa cơ bản

Cho phép một class con (derived class) kế thừa toàn bộ thuộc tính/phương thức từ class cha (base class) — tái sử dụng code, tránh viết lại logic trùng lặp.

```cpp
// Class cha (Base class)
class NhanVien {
  protected:
    int luongCoBan;

  public:
    void datLuong(int luong) {
        luongCoBan = luong;
    }
};

// Class con (Derived class) kế thừa từ NhanVien
class LapTrinhVien : public NhanVien {
  public:
    int thuongDuAn;

    int tinhTongThuNhap() {
        return luongCoBan + thuongDuAn;
    }
};

int main() {
    LapTrinhVien nv;
    nv.datLuong(15000000);   // Phương thức kế thừa từ NhanVien
    nv.thuongDuAn = 3000000;
    cout << "Tong thu nhap: " << nv.tinhTongThuNhap();
    return 0;
}
```

## #72. Multilevel Inheritance - Kế thừa đa cấp

Class C kế thừa từ class B, class B lại kế thừa từ class A — tạo thành chuỗi kế thừa nhiều tầng:

```cpp
class ThietBi {           // Tầng 1
  public:
    string thuongHieu = "Phong Vu";

class Laptop : public ThietBi {   // Tầng 2 - kế thừa ThietBi
  public:
    string dongMay = "Gaming";

class LaptopGamingCaoCap : public Laptop {  // Tầng 3 - kế thừa Laptop
  public:

        cout << thuongHieu << " - " << dongMay << " - Cao cap\n";  // Dùng lại thuộc tính của cả 2 tầng trước
    }
};

int main() {
    LaptopGamingCaoCap sp;
    sp.hienThi();   // "Phong Vu - Gaming - Cao cap"
    return 0;
}
```

## #74. Access Specifiers trong Inheritance (protected)

Bạn đã biết `public` và `private` (bài #68). Specifier `protected` phát huy tác dụng rõ nhất trong ngữ cảnh kế thừa — nó **giống `private`, nhưng class con vẫn truy cập được**:

```cpp
class Employee {
  protected:                // protected: class con truy cập được, bên ngoài thì không
    int salary;
};

class Programmer : public Employee {
  public:
    int bonus;
    void setSalary(int s) { salary = s; }       // ✅ Truy cập được salary (protected)
    int getSalary() { return salary; }
};

int main() {
    Programmer myObj;
    myObj.setSalary(50000);
    myObj.bonus = 15000;
    cout << "Salary: " << myObj.getSalary() << "\n";
    cout << "Bonus: " << myObj.bonus << "\n";
    return 0;
}
```

| Access Specifier ở class cha | Class con có truy cập được không? | Bên ngoài có truy cập được không? |
| ------------------------------ | :----------------------------------: | :-----------------------------------: |
| `public`                       | ✅ Có                                | ✅ Có                                 |
| `protected`                    | ✅ Có                                | ❌ Không                              |
| `private`                      | ❌ Không                             | ❌ Không                              |

## #75. Polymorphism - Tính đa hình

### 1. Khái niệm

"Nhiều hình thái" — cùng một tên phương thức nhưng hoạt động khác nhau tùy class gọi nó, thường dùng kết hợp với Inheritance.

### 2. Đa hình biên dịch (Compile-time) — chính là Function Overloading (bài #58)

### 3. Đa hình runtime — dùng từ khóa `virtual`

```cpp
class DongVat {
  public:
    virtual void keu() {             // "virtual" cho phép class con ghi đè
        cout << "Dong vat phat ra am thanh\n";
    }
};

class Cho : public DongVat {
  public:
    void keu() override {            // Ghi đè (override) phương thức của class cha
        cout << "Cho sua: Gau gau!\n";
    }
};

class Meo : public DongVat {
  public:
    void keu() override {
        cout << "Meo keu: Meo meo!\n";
    }
};

int main() {
    DongVat* dsDongVat[2];
    Cho cho1;
    Meo meo1;

    dsDongVat[0] = &cho1;
    dsDongVat[1] = &meo1;

    for (int i = 0; i < 2; i++) {
        dsDongVat[i]->keu();  // Cùng gọi keu() nhưng mỗi con vật kêu khác nhau
    }
    return 0;
}
```

### 4. So sánh Overloading vs Overriding

| Đặc điểm            | Function Overloading (Nạp chồng)     | Function Overriding (Ghi đè)                     |
| --------------------- | ---------------------------------------- | ---------------------------------------------------- |
| **Xảy ra khi nào**   | Cùng 1 class, nhiều hàm cùng tên          | Class con định nghĩa lại hàm của class cha           |
| **Yêu cầu kế thừa?** | ❌ Không cần                             | ✅ Bắt buộc phải có quan hệ kế thừa                  |

## #76. Templates trong C++

### Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ

Cho phép viết **một hàm hoặc class dùng chung cho nhiều kiểu dữ liệu khác nhau**.

### Function Template

```cpp

```

### Class Template

```cpp
template <class T>
class HopChua {
  private:
    T giaTri;
  public:
    HopChua(T val) { giaTri = val; }
    T layGiaTri() { return giaTri; }

int main() {

    HopChua<string> hopChu("Xin chao");

    cout << hopSo.layGiaTri() << "\n";
    cout << hopChu.layGiaTri() << "\n";
    return 0;
}
```

## #87. Các phương thức Vector thường dùng (thêm/xóa/sắp xếp)

```cpp
#include <vector>
#include <algorithm>

int main() {
    vector<int> soLuongTon = {50, 12, 88};

    soLuongTon.push_back(33);    // Thêm phần tử vào cuối: {50,12,88,33}
    soLuongTon.pop_back();        // Xóa phần tử cuối cùng: {50,12,88}

    cout << soLuongTon.size() << "\n";    // Số lượng phần tử: 3
    cout << soLuongTon.empty() << "\n";   // Kiểm tra rỗng: 0 (false)

    sort(soLuongTon.begin(), soLuongTon.end());  // Sắp xếp tăng dần
    for (int x : soLuongTon) cout << x << " ";    // 12 50 88

    soLuongTon.clear();           // Xóa toàn bộ phần tử
    return 0;
}
```

| Phương thức          | Ý nghĩa                                  |
| ---------------------- | -------------------------------------------- |
| `push_back(x)`         | Thêm phần tử `x` vào cuối vector             |
| `pop_back()`           | Xóa phần tử cuối cùng                        |
| `size()`               | Trả về số lượng phần tử hiện có              |
| `empty()`              | Kiểm tra vector có rỗng không                |
| `clear()`              | Xóa toàn bộ phần tử                          |
| `insert(vt, x)`        | Chèn phần tử `x` vào vị trí `vt`             |
| `erase(vt)`            | Xóa phần tử tại vị trí `vt`                  |

> 🎯 **Lời khuyên thực chiến:** Trong hầu hết dự án C++ hiện đại, `vector` thay thế mảng tĩnh (Chương 12) trong 90% trường hợp vì tính linh hoạt và các hàm hỗ trợ dựng sẵn.

## #94. Iterator - Con trỏ duyệt STL

## #95. Algorithm - Thư viện thuật toán có sẵn

Thư viện `<algorithm>` cung cấp sẵn các thuật toán phổ biến, áp dụng được cho hầu hết mọi container STL:

```cpp
#include <algorithm>
#include <vector>

int main() {
    vector<int> soLuongTon = {50, 12, 88, 5, 33};

    sort(soLuongTon.begin(), soLuongTon.end());          // Sắp xếp tăng dần
    for (int x : soLuongTon) cout << x << " ";            // 5 12 33 50 88
    cout << "\n";

    reverse(soLuongTon.begin(), soLuongTon.end());        // Đảo ngược thứ tự
    for (int x : soLuongTon) cout << x << " ";            // 88 50 33 12 5
    cout << "\n";

    auto viTri = find(soLuongTon.begin(), soLuongTon.end(), 33); // Tìm kiếm
    if (viTri != soLuongTon.end()) {
        cout << "Tim thay 33 trong danh sach";
    }
    return 0;
}
```

| Hàm                          | Ý nghĩa                              |
| ------------------------------ | ---------------------------------------- |
| `sort(begin, end)`             | Sắp xếp tăng dần                         |
| `reverse(begin, end)`          | Đảo ngược thứ tự các phần tử             |
| `find(begin, end, giaTri)`     | Tìm kiếm giá trị, trả về iterator        |
| `max_element(begin, end)`      | Tìm phần tử lớn nhất                     |
| `min_element(begin, end)`      | Tìm phần tử nhỏ nhất                     |

# CHƯƠNG 26: NAMESPACE TRONG C++

## #96. Namespace - Không gian tên

### Khái niệm — KHÁI NIỆM MỚI, C KHÔNG CÓ

Namespace dùng để **nhóm các tên (biến, hàm, class) lại với nhau**, tránh xung đột tên khi 2 thư viện/module khác nhau vô tình đặt trùng tên — đây chính là nguồn gốc của `using namespace std;` bạn đã dùng xuyên suốt tài liệu này.

```cpp
namespace KhoHang {
    int soLuongTon = 100;
    void hienThiTonKho() {
        cout << "So luong ton: " << soLuongTon;
    }
}

namespace CuaHang {
    int soLuongTon = 50;   // Trùng tên biến với namespace KhoHang nhưng KHÔNG xung đột
}

int main() {
    cout << KhoHang::soLuongTon << "\n";  // Truy cập qua toán tử phạm vi ::
    cout << CuaHang::soLuongTon << "\n";
    KhoHang::hienThiTonKho();
    return 0;
}
```

> 📌 `std` chính là namespace chứa toàn bộ thư viện chuẩn C++ (`cout`, `cin`, `vector`, `string`...). Viết `using namespace std;` nghĩa là: "cho phép dùng thẳng tên trong namespace std mà không cần viết `std::` phía trước" (xem lại bài #26 - Omitting Namespace).

# CHƯƠNG 27: BẢNG SO SÁNH TỔNG HỢP C vs C++

## #97. So sánh chi tiết C và C++

### Bảng tổng hợp toàn diện — dùng để ôn tập nhanh trước khi phỏng vấn hoặc chuyển đổi tư duy

| Tiêu chí                     | C                                          | C++                                                          |
| ------------------------------ | --------------------------------------------- | ---------------------------------------------------------------- |
| **Mô hình lập trình**         | Thủ tục (Procedural)                          | Đa mô hình: Thủ tục + Hướng đối tượng (OOP)                      |
| **File mã nguồn**             | `.c`                                          | `.cpp`, `.cc`, `.cxx`                                             |
| **Trình biên dịch**           | `gcc`                                         | `g++`                                                             |
| **Xuất/Nhập dữ liệu**         | `printf()` / `scanf()`                        | `cout` / `cin`                                                    |
| **Kiểu chuỗi**                | `char[]` + `<string.h>`                       | `string` object + `<string>` (song song vẫn hỗ trợ char[])       |
| **Cấp phát bộ nhớ động**      | `malloc()`, `calloc()`, `realloc()`, `free()` | `new`, `delete`, `new[]`, `delete[]`                              |
| **Con trỏ null**              | `NULL`                                        | `nullptr` (an toàn kiểu hơn)                                      |
| **Tham chiếu (Reference)**    | ❌ Không có, chỉ có con trỏ                   | ✅ Có (`&`), thay thế con trỏ trong nhiều trường hợp              |
| **Struct**                    | Không chứa hàm, không có access specifier     | Có thể chứa hàm, có access specifier                              |
| **Class & Object**            | ❌ Không hỗ trợ                               | ✅ Hỗ trợ đầy đủ                                                  |
| **Nạp chồng hàm (Overload)**  | ❌ Không hỗ trợ                               | ✅ Hỗ trợ                                                         |
| **Tham số mặc định**          | ❌ Không có                                   | ✅ Có                                                             |
| **Kế thừa (Inheritance)**     | ❌ Không có                                   | ✅ Có (đơn, đa cấp, đa kế thừa)                                   |
| **Đa hình (Polymorphism)**    | ❌ Không có                                   | ✅ Có (`virtual`, `override`)                                     |
| **Template / Generic**        | ❌ Không có (dùng macro hoặc `void*`)         | ✅ Có (Function Template, Class Template)                          |
| **Lambda**                    | ❌ Không có                                   | ✅ Có (từ C++11)                                                  |
| **Xử lý lỗi**                 | Trả mã lỗi thủ công / `errno`                 | `try / catch / throw`                                             |
| **Cấu trúc dữ liệu dựng sẵn** | ❌ Không có, phải tự cài đặt                  | ✅ STL: `vector`, `list`, `stack`, `queue`, `map`, `set`...        |
| **Namespace**                 | ❌ Không có                                   | ✅ Có                                                             |
| **Vòng lặp for-each**         | ❌ Không có                                   | ✅ Có (Range-based for, từ C++11)                                 |
| **Ứng dụng nhúng**            | Rất phổ biến (nhẹ, tối ưu tối đa)             | Vẫn dùng được, phù hợp dự án cần tổ chức code lớn hơn (OOP)       |

> 🎯 **Tổng kết bằng một câu:** Nếu C dạy bạn cách **điều khiển máy tính ở mức thấp một cách chính xác**, thì C++ dạy bạn cách **tổ chức một hệ thống phần mềm lớn, dễ bảo trì và mở rộng** — bằng cách xây thêm lớp trừu tượng OOP lên trên chính nền tảng C bạn đã có.

## #99. Bài tập tổng hợp: Quản lý danh sách sản phẩm bằng Class + STL

### Yêu cầu

Xây dựng chương trình quản lý sản phẩm, áp dụng tổng hợp: **Class + Encapsulation + Constructor + Vector + Algorithm** — mô phỏng bài toán quản lý SKU/tồn kho trong thực tế công việc Trade Marketing.

- Mỗi sản phẩm gồm: tên, giá, số lượng tồn.
- Cho phép thêm sản phẩm vào danh sách (dùng `vector`).
- Tính tổng giá trị tồn kho.
- Sắp xếp danh sách theo giá tăng dần (dùng `<algorithm>`).

### Code tham khảo

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

class SanPham {
  private:
    string ten;
    float gia;
    int soLuongTon;

  public:
    SanPham(string t, float g, int sl) {   // Constructor
        ten = t;
        gia = g;
        soLuongTon = sl;
    }

    float layGia() const { return gia; }              // Getter
    float tinhGiaTriTon() const { return gia * soLuongTon; }

    void hienThi() const {
        cout << ten << " | Gia: " << gia << " VND | Ton: " << soLuongTon << "\n";
    }
};

int main() {
    vector<SanPham> danhSachSP;   // Vector chứa các Object thuộc class SanPham

    danhSachSP.push_back(SanPham("Chuot khong day", 250000, 30));
    danhSachSP.push_back(SanPham("Ban phim co", 890000, 15));
    danhSachSP.push_back(SanPham("Man hinh 24 inch", 3500000, 8));

    // Sắp xếp theo giá tăng dần bằng Lambda + Algorithm
    sort(danhSachSP.begin(), danhSachSP.end(), [](const SanPham &a, const SanPham &b) {
        return a.layGia() < b.layGia();
    });

    cout << "=== DANH SACH SAN PHAM (SAP XEP THEO GIA) ===\n";
    float tongGiaTriTonKho = 0;
    for (const auto &sp : danhSachSP) {
        sp.hienThi();
        tongGiaTriTonKho += sp.tinhGiaTriTon();
    }

    cout << "\nTong gia tri ton kho: " << tongGiaTriTonKho << " VND";
    return 0;
}
```

### Giải thích các điểm áp dụng kiến thức đã học

| Kiến thức áp dụng          | Vị trí trong code                                              |
| ----------------------------- | ------------------------------------------------------------------ |
| Class + Encapsulation (#63, #69) | `private` cho dữ liệu, `public` cho getter/hiển thị              |
| Constructor (#66)             | `SanPham(string t, float g, int sl)`                               |
| Vector - STL (#85)            | `vector<SanPham> danhSachSP` chứa các object                       |
| Lambda (#61)                  | Hàm so sánh truyền vào `sort()`                                     |
| Algorithm (#95)               | `sort(danhSachSP.begin(), danhSachSP.end(), ...)`                   |
| Range-based for (#42)         | `for (const auto &sp : danhSachSP)`                                 |
